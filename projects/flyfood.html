Overview

เป้าหมาย

ฝึกสร้างแอป Android ตั้งแต่ออกแบบหน้าจอ เปลี่ยนหน้า ไปจนถึงเก็บข้อมูลในเครื่อง เป็นโปรเจกต์ทดลอง ยังไม่ได้เชื่อมเซิร์ฟเวอร์ ระบบชำระเงิน หรือระบบจัดส่งจริง

สิ่งที่ผมทำ

  • หลายหน้าจอ เชื่อมกันด้วย Activity และ Intent
  • เก็บข้อมูลด้วย SQLite
  • ระบบตะกร้า ปรับจำนวน และคำนวณราคารวม
  • UI animation และ custom drawable

Tech stack

Kotlin · Android Studio · XML Layout · SQLite · AndroidX · Material Components · Gradle Kotlin DSL

What’s next

  • ระบบสมัครสมาชิกและเข้าสู่ระบบที่เก็บข้อมูลได้จริง
  • เชื่อมต่อ API หรือฐานข้อมูลออนไลน์
  • ประวัติการสั่งซื้อ
  • ค้นหาและกรองประเภทอาหาร
  • ระบบชำระเงิน
  • ปรับโครงสร้างโค้ดและเพิ่มการทดสอบ
